## 💻 About This Portfolio Application

This portfolio is built as an enterprise-grade, single-page application demonstrating modern frontend architecture, accessibility, dynamic theming, and test-driven engineering.

### Architecture Highlights
- **Domain-Driven Feature Slicing**: Features (`architecture`, `experience`, `projects`, `skills`, `patents`, `contact`) are encapsulated with dedicated components and unit tests.
- **Interactive Banking Architecture Visualizer**: Live interactive simulator illustrating real-time event propagation through API Gateway, Microservices, and Kafka Broker.
- **Dual Theme Support**: Flawless Light and Dark mode with custom glowing accents, persistent state, and system theme auto-detection.
- **Custom UI System**: Glassmorphism cards, glowing cursor animation, and responsive modals.
- **100% Test Coverage**: Verified across statements, branches, functions, and lines.

```
ReactUI/
├── src/
│   ├── components/       # Common navbar, footer, layout, atomic UI primitives
│   ├── context/          # ThemeContext (Light/Dark mode)
│   ├── data/             # Strongly-typed single source of truth (portfolioData.ts)
│   ├── features/         # Hero, About, Architecture, Experience, Projects, Skills, Patents, Contact
│   ├── hooks/            # useScrollSpy, useClipboard, useTheme
│   ├── types/            # TypeScript domain interfaces
│   └── utils/            # Utility helpers (cn classnames merge)
```
